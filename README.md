# Hiraya Manawari: Sales Dashboard

An end-to-end sales analysis for a fictional Philippine online clothing
store on a Shopee/Lazada-style marketplace.

> **Note:** All data in this project is synthetic (generated with Python)
> and does not represent a real business.

## Project Goal
Help the store owner understand what sells, where, and how customers pay,
using Python, SQL, and Excel.

## Tools
Python (pandas, numpy) | SQL | Excel
